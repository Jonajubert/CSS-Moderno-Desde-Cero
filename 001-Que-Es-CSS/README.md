# CSS Moderno Desde Cero

## Capítulo 001 - ¿Qué es CSS?

CSS significa **Cascading Style Sheets** (Hojas de Estilo en Cascada).

Su función es definir la apariencia de una página web.

Mientras HTML organiza el contenido, CSS permite modificar cómo se verá ese contenido.

## ¿Qué aprenderemos?

- Qué es CSS.
- Cómo se relaciona con HTML.
- Cómo aplicar estilos básicos.

## Ejemplo

HTML

```html
<h1 class="titulo">¡Hola Mundo!</h1>
```

CSS

```css
.titulo{
    color: royalblue;
}
```

## Resultado

El título se mostrará en color azul.

## Ejercicio

Modificá el ejemplo anterior para:

- Cambiar el color del título.
- Cambiar el tamaño del texto.
- Agregar un color de fondo a la página.
